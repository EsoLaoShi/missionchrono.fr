Connexion

Cette page publie directement sur le dépôt GitHub du site. Elle nécessite un jeton d'accès personnel GitHub, créé une seule fois :

  1. Sur GitHub : Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Resource owner : le compte propriétaire du dépôt missionchrono.fr
  3. Repository access : Only select repositories → missionchrono.fr
  4. Permissions → Contents : Read and write
  5. Générer, copier le jeton (commence par github_pat_) et le coller ci-dessous
Le jeton reste uniquement dans ce navigateur (stockage local) — il n'est jamais envoyé ailleurs qu'à GitHub.
